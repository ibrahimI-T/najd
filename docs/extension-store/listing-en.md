# Store listing — English (Chrome Web Store and Microsoft Edge Add-ons)

Name: NAJD AGENT — AI Browser Assistant
Short description (max 132): Connects your browser to the NAJD AGENT desktop app: it browses for you, finishes tasks and answers in a side panel. Local only.
Category: Productivity

## Detailed description

NAJD AGENT is your personal assistant on your own computer. This extension connects your browser to the NAJD AGENT desktop app so NAJD can browse for you and so you can ask it for help without leaving the page.

What you can do
- Ask NAJD from any page: type a question in the side panel, select text and right-click, or ask about the current page.
- Let NAJD browse in its own tab group: search, open sites, read pages and follow links.
- Stay in control: typing, choosing options and pressing buttons need your approval in the NAJD app. Card numbers are never typed by the extension, and a saved account password is filled only when you ask NAJD to sign in, directly from the app, without the AI model ever seeing it.
- Use the sites you are already signed in to.

Private by design
- The extension talks only to the NAJD app on your computer (127.0.0.1). It has no servers of its own.
- Your questions are answered by the AI provider you chose in the NAJD app; what you ask, and any page details you choose to share, are handled by that provider under its own terms.
- It has no servers, no analytics and no remote code.
- Website access is optional: you grant it from the panel and can revoke it in the browser at any time.
- Linking needs your confirmation: the same six-digit code is shown in the extension and in a NAJD window.

Requires the NAJD AGENT desktop app for Windows.

## Single-purpose statement

Connect the browser to the user's local NAJD AGENT app so the user can ask it for help and let it browse in its own tab.
