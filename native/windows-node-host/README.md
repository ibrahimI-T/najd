# NAJD private Windows node host

Internal module, not a replacement application. Reuses the pinned upstream OpenClaw.Shared MCP transport and SystemCapability under the retained MIT notice. Source transfer is by ProjectReference; no upstream branding assets or user profiles are imported.

HTTP exposes only `system.which`, restricted to fixed notepad, calc, mspaint, chrome and edge IDs. The original resolver handles System32; Chrome/Edge use read-only HKLM App Paths and exact protected Program Files candidates with reparse rejection. Registry values never authorize arbitrary executables. Production private stdio additionally exposes `najd.windows.demo`, restricted to the approved Chrome/Edge fixture described in docs/SPEC-windows-demo.md. No arbitrary shell, notification, screen, camera, microphone, document or approval-store access is granted. Both production operations pass through authoritative core allow-once approval. Optional HTTP mode uses a fresh token for isolated transport proof; browser headers are refused.

The stdio host optionally connects an isolated WindowsNodeClient identity to the owned loopback Gateway. It advertises zero Gateway action commands. A pending device request crosses only the owned pipe; main verifies exact device/request IDs, node-host identity, node-only role and empty scopes before using the dedicated upstream devices CLI/local-owner validation. An explicit acknowledgement starts a fresh socket after approval. Tokens never enter renderer, argv or logs. A pairing receipt records the successful handshake; it is not a live health indicator. Stop/owner EOF closes the host.

Compile with the project-owned SDK into ignored .runtimes/; NuGet restore is locked to packages.lock.json. UIA3 uses the exact Interop.UIAutomationClient package with its full MIT notice copied to output alongside the upstream notice. Real Gateway pairing, core permissions and two-application action proof pass in the source desktop smoke. Carry all upstream/transitive notices and audit the complete payload before installer inclusion; this module is not bundled in a release yet.
