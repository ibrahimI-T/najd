# Canvas

Load the workstation toolset. Use najd_workstation "dashboard_list" first, then "dashboard_create" with a clear title; the user approves it.

Widgets are added and arranged by the user on the Dashboard screen (metric, note, list, chart). Give the user the exact values to enter. Charts use a chart block with labels and series.
