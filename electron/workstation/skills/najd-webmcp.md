# WebMCP

Call najd_workstation "tab_webmcp" on the open tab. It lists only what the visible page declares; an empty list means none. Never assume a tool exists. Reading the list is all NAJD can do today: calling a page tool is not available yet, so use "tab_observe" and "tab_act" instead.
