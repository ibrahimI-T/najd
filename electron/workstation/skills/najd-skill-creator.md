# Skill creator

Find the trigger and the steps from what the user actually did. Keep the description specific about when to use it. Keep the steps short and name real tools.

Save it with najd_workstation action "skill_save" (title: the name, text: when to use it, prompt: the steps); the user approves it in chat and it appears under Skills > Added. Saving again with the same name updates it. To share one as a package, read najd-plugin-builder.
