# Design

Ask for the size and the purpose only if they cannot be assumed. Build the piece as a self-contained HTML page or SVG, with real text and a clear hierarchy, then check it with najd_web_preview.

For a PPTX, read najd-slides. For a picture, use najd_image_generate when a media provider is set up. Report the file path.
