# Slides

Outline the deck first: one message per slide. Build it through the Office kit with Python, then render the slides and look at them with the office review tool before reporting.

Fix overflow and empty placeholders. For small changes to an existing deck, read najd-pptx-surgical-edit. Report the saved path.
